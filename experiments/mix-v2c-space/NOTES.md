# V2C — 更连贯的人声空间

用户已认可 V2B 的伴奏／人声平衡，希望混响更多、更自然，人声更融入整首歌。本次以 V2B 为直接比较对象，重新制作外加的浅层与长尾混响；正式 V1 与旧候选文件保留。

## 成品与对照

- `MUSIC_MIX_V2C_SPACE.mp3` / `.wav`：完整混音，214.27375 秒。
- `MUSIC_V2B_TO_V2C_MIX_COMPARE.mp3`：整曲上下文的等响对照。
- `MUSIC_V2B_TO_V2C_VOCAL_COMPARE.mp3`：人声独奏的等响对照，便于分辨新增空间。
- `MUSIC_MIX_V2C_SPACE_VOCAL.wav`：完整人声分轨。
- `MUSIC_MIX_V2C_SPACE_VOCAL_FX.wav`：衬层、原句尾 echo 与新混响的总和。
- `MUSIC_MIX_V2C_SPACE_REVERB.wav`：仅本次两层新混响的总和。

两份对照都是 **0–20.25 秒为 V2B，20.75–41 秒为 V2C**。每组依次取原曲 58–72 秒与 98–104 秒，中间留 0.25 秒；混音对照约 −16 LUFS，人声对照约 −20 LUFS。建议先听混音对照，留意持续音是否有更多包围感、句尾是否连贯，以及下句字头是否仍清楚。独奏用于听变化，最终位置以伴奏里的表现为准。

## 观察与制作选择

V2B 的外加浅层混响，在人声活跃段平均比 CORE 低约 29 dB；原较长尾声只由少数句尾触发。用户的“位置还没坐进去”是试听反馈；这些测量提示可以尝试更连贯的空间连接，但不能单凭电平证明主观问题的原因。

本次保留 V2 CORE、持续音衬层、句尾 echo 与 V2B BEAT 的原始浮点分轨和电平。只替换两个外加混响返回。CORE 本身已含历史打印效果，下面的数值仅描述可单独控制的外加返回，不代表歌曲的全部混响。

| 参数 | 浅层连接 | 较长尾声 |
| --- | --- | --- |
| 预延迟 | 22 ms | 48 ms |
| 中低／高频衰减参数 | 0.75 / 0.45 s | 1.60 / 0.95 s |
| 发送与返回的带宽 | 约 390–6500 Hz | 约 500–6500 Hz |
| 活跃段返回 RMS，相对 CORE | −26 dB | −27 dB |
| 演唱时返回最多压低 | 2 dB | 4 dB |
| 新句进入时额外最多压低 | 1 dB | 2.5 dB |
| 发送选择 | 原干声活动控制 | 活动控制，并偏向持续歌声 |

短层更早接上主唱，尾声层从少数句尾扩展到更连续的歌声。两层采用密集扩散的合成脉冲响应，高频比中频衰减更快；没有加入稀疏的小房间反射点。返回由原干声电平控制，8 ms attack / 145 ms release，句首另有平滑避让。这些是制作参数，不是对原录音房间的测量，也不能直接等同于某个商业混响插件的预设。

长尾发送权重为 `0.35 + 0.65 × 持续音选择`，经过 65 / 140 ms 平滑。原有 echo 保持原节奏。新合成返回替代旧 shallow/deep，没有把两套返回同时叠起来。

如果在 Ableton 的 Valhalla 或 Pro-R 中参照这套思路，可用两个 100% wet 返回分别建立短扩散空间与较暗的长尾，再做侧链避让。表中的 −26 / −27 dB 是**返回相对 CORE 的实测 RMS**，不是发送旋钮的固定读数；不同插件增益与衰减结构不同，必须重新校准。

## 检查结果

- 活跃段外加混响总量相对 V2B 增加 **5.38 dB**，相对 CORE 约 **−23.52 dB**；持续音区约 **−22.09 dB**。
- 完整人声活跃段 RMS 仅增加约 **0.013 dB**。这是空间返回变化，主唱与伴奏的输入比例保持原值。
- 母带 WAV **−11.57 LUFS / −1.38 dBTP**；MP3 **−11.58 LUFS / −1.10 dBTP**。上一版 WAV 为 −11.58 LUFS，整体响度基本一致。
- 沿用 +5.03 dB 总线驱动、192 kHz 过采样、−1.4 dBFS ceiling、5 ms attack / 80 ms release。近似限幅 P95 为 **1.84 dB**，活动窗超过 3 dB 的约 **1.55%**。
- 人声活跃段各检查频带平均能量变化小于 **0.022 dB**；这不等于证明没有主观遮挡，只用于排查显著音色漂移。
- 分轨求和、原 CORE／BEAT／衬层／echo 校验、单声道折叠、帧数、PCM24 回读与 MP3 峰值检查通过。详细结果见 `space-check.json`、`export-check.json` 与 `validation.json`。

## DAW 路由与继续制作

全部 WAV 为 48 kHz / 24-bit / stereo，零点对齐。Ableton 中关闭 Warp，Clip Gain 与轨道推子设 0 dB：

1. 直接使用本版 VOCAL，加 [V2B BEAT](../mix-v2b-balance/MUSIC_MIX_V2B_BEAT.wav)，得到母带前混音。
2. 或使用 [V2 CORE](../mix-v2-candidate/MUSIC_MIX_V2_CANDIDATE_VOCAL_CORE.wav)，加本版 VOCAL_FX，再加 V2B BEAT。

VOCAL 已包含 CORE 和 FX，VOCAL_FX 已包含 REVERB。不要重复叠加。若只想微调新混响，可在上述组合中同相加上 REVERB 增加返回，或用反相／差分增益减少返回；最好先在独立总线确认路由。分轨没有套最终母带限制器，成品另含总线处理。

`build_space.py` 保存实际空间处理，`render_exports.py` 保存母带与对照方法；二者依赖本次工作区内的旧浮点分轨。`space-design.json` 记录输入校验与参数，`controls.npz` 保存新包络，脉冲响应保存在 `shallow_ir.f32` / `deep_ir.f32`（48 kHz、双声道、交错 float32 little-endian）。公开的 CORE、FX、REVERB、VOCAL 和对应 BEAT 可供后续继续混音；公开 PCM24 分轨与内部 float32 存在微小量化差异。

这是基于信号分析的制作实验，没有进行模型主观试听。是否更自然、更接近用户所希望的《1 Call》制作感觉，由等响试听判断；没有使用或混入参考歌曲的声音。本版尚未设为新的正式 V2。
