# 混音实验 V2 候选 — V1 的整体与人声精修

本版从已获认可的正式 V1（原实验 V13）及其母带前分层继续处理。目标是沿《1 Call》的制作方向，把较弱持续音的支撑、高频顺滑度和少数伴奏峰值对整曲的影响再整理一层。改动刻意保持较小，V1 仍为正式基线；这版等待用户试听决定是否成为正式 V2。

## 为什么选这三项小改动

V1 的较弱与较强持续音，主体中位电平已经接近；较强唱句的电平变化也不大。两段参考估计人声并没有比 V1 更平。参考整曲较密的低频 RMS 很大程度受持续低音编曲影响，无法据此推导 V1 需要同样的全曲压缩。

因此，本版以现有音色和调音为基础，集中处理三个局部关系：高频相对突出时的边缘、较弱持续音的现有侧衬层、进入母带前的少数伴奏峰。不同歌曲的能量比较及模型估计参考人声只提供制作线索，不能识别该歌手真实插件链或把某个统计差异等同于声学缺陷。

## 相对 V1 的实际处理

### 1. 主唱的局部高频顺滑

在现有 CORE 上使用 **8 kHz / Q0.8、额外最多 −0.8 dB** 的宽钟形动态衰减。检测 5–9.5 kHz 对 700 Hz–4 kHz 的功率比，从 −2 到 +4 dB 平滑映射到处理量，并受原始人声活动控制。控制帧 5 ms、功率高斯平滑约 7.5 ms，attack 5 ms / release 75 ms；左右使用同一控制量。

超过 0.25 dB 的动作累计约 **16.97 秒**。最后配平 +0.04 dB，使主体整体响度接近 V1。独立测得活动段 5–10 kHz 平均变化约 **−0.137 dB**，强持续元音基本只受到这 0.04 dB 配平；主要厚度和句子动态保持。检测出的只是相对高频突出，包含自然辅音，不把每处动作都称作坏齿音。

### 2. 较弱持续音的侧向支撑

沿用已有持续音候选及合成 doubles。原 dry 在选中持续音的 40% 分位约 **−30.75 dBFS**，用 4 dB 软过渡控制较弱部分；只提升该层的 **Side，最多 +0.8 dB**，180 ms 进入、230 ms 退出，并在句头抑制。

超过 +0.25 dB 的区域约 **12.43 秒**。较弱持续音完整人声 Side/Mid 由约 −14.38 变为 −14.11 dB，实际增加约 **0.28 dB**；较强持续音变化约 −0.03 dB，整段活动只增加约 0.06 dB。主唱原音高、发音位置以及衬层的微移调、延迟沿用 V1；echo、shallow、deep 三层逐样本保持原样。

### 3. 伴奏峰值与母带的衔接

从 V1 的近似限幅变化和已知伴奏／人声分量中找出 **28 个候选事件**：1 ms 窗估计增益衰减局部峰至少 4.3 dB，并在附近 50 ms 内要求伴奏 RMS 比人声高至少 3 dB，以及低频上下文达到门限；再定位附近真实伴奏样本峰。门限用于选择操作位置，不是鼓类型识别或因果诊断。

在伴奏上施加左右联动的连续音量包络：实际最大修整量按事件为 **0.350–0.694 dB**，提前 8 ms、5 ms 半余弦进入、保持到峰后 4 ms，以 50 ms 时间常数恢复，尾部平滑结束。所有事件合计超过 0.1 dB 的时长约 **2.50 秒**。这是稀疏局部音量修整，低频的长期能量变化很小。

沿用 V1 的末端限幅设置：192 kHz 过采样，ceiling −1.4 dBFS，attack 5 ms / release 80 ms，关闭自动补偿、补偿延迟。总线驱动由 V1 的 +5.74 dB 变为 **+5.73 dB**，目标保持原整体响度。

## 成品核验

- 完整 WAV：**−11.56 LUFS / −1.38 dBTP**；MP3：**−11.56 LUFS / −1.06 dBTP**。与 V1 完整 WAV 的整体响度差约 0.01 LU。
- 28 个修整事件中，25 个窗口的最大近似限幅量降低超过 0.05 dB，中位减少约 **0.18 dB**；没有事件恶化超过 0.05 dB。这是小幅局部收益，不代表整首有巨大变化。1 ms 估计受重采样影响，不是限制器内部仪表。
- 另用实际输入峰和 5／10／20 ms 输入输出能量比交叉检查，事件输入峰中位降低约 0.186 dB，短窗有效衰减中位减少约 0.15–0.18 dB，方向一致。
- 排除修整事件附近的正常段，限幅 P95 约 1.576 → 1.571 dB；40 ms 峰均比变化中位接近零。最终整曲 95% 活动毫秒窗的估计限幅不超过约 1.835 dB。
- 伴奏 25–70 / 70–140 Hz 长期能量变化约 −0.0365 / −0.0285 dB；并非靠持续削弱低音取得结果。
- 完整母带折单声道能量约 −0.284 dB，与 V1 基本一致。人声六处唱句检查最佳时移均为零，主体电平变化范围基本保持。
- 已回读所有 WAV／MP3，检查声道、采样率、帧数、峰值、分轨关系；对照编码后响度误差不超过 0.01 LU。正式 V1 的七个音频哈希重新核验一致。

这些是技术检查，没有模型主观试听，不能保证每位听者都觉得升级或已达到商业唱片的审美标准。V2 是沿用户认可声音做的细修方案；请优先用等响混音对照判断顺滑、支撑和整体自然度。
