# V2 人声升级建议（V1 保守延续）

只读检查 V13/V1 浮点主体、人声整体、四个新增返回及活动控制，并比较《1 Call》两个模型估计人声片段。没有主观试听。不同歌曲并非同一唱段、音高、元音；参考含分离误差。数值不能证明听感或原制作插件。

## 现在不应重复做的事

- 主体强声已经稳定。40–70 / 100–130 秒 40 ms 活跃电平 P95−P50 为 2.44 / 1.90 dB，参考为 3.34 / 3.15 dB。参考并不比当前主体更平。按原 dry 大小划分较弱和较强的持续音，当前 CORE 中位电平为 −20.43 / −20.35 dB，已经非常接近。因此没有新证据支持常开慢压缩、全频向上压缩或再提弱字。
- 1.2–5 kHz 与参考归一能量仍很接近，不加统一 presence。150–400 Hz 的差值受音高/元音影响，而且用户已认可 V1；不做参考频谱强制匹配，不再削一整块厚度。
- 强持续音的当前人声 Side/Mid 已 −10.89 dB；参考两段整体约 −9.88 / −9.38 dB。比较口径不同，但至少说明不应再全局扩宽。不要再叠全时微移调，不改主唱音高/共振峰。
- 原谐波残差早已打印进主体，再加饱和缺少独立证据。主体包含旧空间，不可当作原始干声去大力上压。

## 建议只试两项

### 1. 给较弱持续音现有侧衬层轻微补足

较弱持续音当前 doubles/Core 为 −17.32 dB、完整人声 Side/Mid 为 −14.38 dB；较强持续音为 −13.00 / −10.89 dB。这支持仅微调某些较弱持续音的衬层，而不整体增加混响。

- 用现有 `voiced > 0.7`、`activity > 0.8`，以及原 dry 持续音电平较弱约 40% 的区域作为候选，候选门限软化 3–5 dB，控制必须平滑。
- 只处理现有 doubles 的 Side；Mid 原样保留。额外提升上限 **0.8 dB** 起步，最多 **1.2 dB**。不要向本来接近无声的层补入新内容。
- 150–200 ms 进入、180–250 ms 退出；遇到现有句头控制时抑制。保留 V1 的微移调值、延迟值、发送范围。
- 预期只是较弱持续元音稍有周边支撑；不能把它称为生成该歌手嗓音。幅度很小，可能整曲变化不明显，这比整体 chorus 化更符合此次“不要怪”的要求。
- 边界：强持续音侧声变化 ≤0.1 dB；完整人声主要活动 Side/Mid 不应整体增加超过约 0.5 dB；单声道主体不被削弱。不要把宽度拉到参考统计值当目标。

### 2. 只收相对突出的摩擦音高频，不继续提亮

V1 主体 5–9.5 kHz / 700 Hz–4 kHz 40 ms 能量比在活动帧 P90 为 −0.70 dB、P95 +2.20 dB，而强持续音 P95 只有 −5.46 dB。这是候选高频突出指标，不是自动确认的“坏齿音”。23.12 秒活动帧超过 −3 dB，涵盖自然辅音，不能全部深压。

- 可试宽钟形 **7.8–8.2 kHz / Q 0.7–0.9**，最大额外 **−0.6 至 −0.8 dB**。不加新的高架或全频压缩。
- 侧链取 5–9.5 kHz 对 700 Hz–4 kHz 的相对能量，约 −2 dB 开始，至 +4 dB 达到上限。以绝对活动门限挡住静音和极弱尾声。双声道联动。
- 3–6 ms attack / 60–90 ms release，软控制；现有 V12 的 6.5 kHz 动态仍在，因此额外动作宁少。
- 预期是响亮辅音略顺、更容易在后续母带保持平滑；不是去掉个性气声。副作用是叠加去齿导致含混，若 5–10 kHz 活跃平均衰减超过约 0.25–0.35 dB，优先减量。不要自动以参考高频均值为目标。

## 对并行密度/新压缩的结论

本轮没有充分证据推荐新增。当前主体 40 ms 峰均比中位约 10.63 / 10.71 dB，参考 9.44 / 9.77 dB，存在约 1 dB 差值；但短窗峰均比受元音和齿音影响，且参考来自已母带、已分离信号，不能据此判定还缺一层压缩。总线若已有非常轻的、经等响比较的整合处理，先完成它；不要同时在主体再上压，使房间底色和合成衬层被抬出。

详细测量和可复查脚本见 `analysis.json`、`analyze.py`。建议并非都必须叠加；若只选一项，优先 0.6–0.8 dB 的局部 HF 顺滑，保留主体与返回现有总体关系。
