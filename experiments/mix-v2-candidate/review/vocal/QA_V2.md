# V2 人声候选独立核验

使用初审相同的 V1 控制、40 ms 窗口和强弱持续音划分，九项检查均通过。脚本 `qa_v2.py`，完整数据 `qa_v2.json`。

- 主体活动段 5–10 kHz 能量变化 **−0.137 dB**，10–16 kHz **−0.148 dB**，表明收束较轻。强持续音上述变化 **+0.039 / +0.039 dB**，基本只是全局 +0.04 dB 配平，动态去齿几乎没有压它；较弱持续音为 **−0.042 / −0.025 dB**。
- 较弱持续音完整人声 Side/Mid 由 **−14.385 → −14.105 dB**，增加 **0.279 dB**；较强持续音 **−10.889 → −10.919 dB**，变化 **−0.030 dB**。整段活动只增加 **0.061 dB**，没有全局大幅拓宽。较强持续音和句头没有超过 0.25 dB 的侧衬层提升。
- 两个主体片段的 P95−P50 分别由 **2.438 → 2.438 dB**、**1.900 → 1.910 dB**；没有显著压平。P90−P10 变化不超过 0.060 dB。
- 六处唱句相关性检查最佳时移均 **0 样本**，零延迟相关度最低 **0.99982**。
- echo、shallow、deep 与 V1 **逐样本一致**。doubles Mid 最大误差 **7.45e−9**、总 FX Mid **1.12e−8**，仅浮点舍入；这些层折单声道能量变化为 0 dB。
- 完整人声折单声道能量仅增加 **0.021 dB**。CORE + FX = VOCAL，四层相加 = FX，浮点检查误差均 0。全部格式长度匹配、有限值，未出现满刻度溢出。

结论：这两项是克制的局部变化，数值上保留主体厚度、动态、时序和强元音空气感，宽度增强确实落在较弱持续音。没有发现需要返工的人声技术问题。仍需用户等响试听决定美感提升是否足够；检查不能证明某歌手的身份音色，也不能保证录音固有空间感消失。母带的响度、低频峰值和全混音立体声需另行审核。
