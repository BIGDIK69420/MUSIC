# V1（旧 V13）母带只读复核

本复核仅测量现有文件；未主观试听、未修改音频。处理差异能被测出，不等于审美提升已被证实。完整数值及方法在 `master-analysis.json` 和 `analyze_master.py`。

## 结论

**保留 V1 的整体频响、宽度和响度。不建议因“唱片感”额外堆叠宽频 EQ、加宽或持续总线压缩。可试一个有明确作用范围的改动：对少数伴奏主导的高峰做极轻电平修整，让现有末端限制器少做一点工作。**

## 主要证据

- V1：−11.55 LUFS、−1.38 dBTP、LRA 5.10 LU。参考：−10.02 LUFS、+2.24 dBTP、LRA 7.40 LU。参考转码后的正真峰值不是应模仿的指标。
- V1 原限幅的活跃 1 ms 估计 GR：P95 1.84 dB、P99 3.32 dB、最大 6.02 dB，超过 3 dB 仅约 1.50%。因此总体并非持续严重过压；关注少数事件即可。
- 分别把完整音频配平至 −16 LUFS 后，参考 25–70 Hz 活跃带 RMS 为 −16.58 dBFS，V1 为 −26.81 dBFS；该频带的 1 秒包络 P90−P10 分别为 0.59 dB 和 35.19 dB。参考 30.9 Hz / 41.2 Hz 的显著音乐低音持续支撑 RMS。参考更低的全频短时峰均比不能被解释为 V1 应全面压缩到同样密度。
- 中频慢包络更接近：300–700 Hz 的 1 秒 P90−P10，V1 6.01 dB / 参考 6.43 dB；700–1500 Hz 为 9.27 / 8.76 dB；1.5–3.5 kHz 为 8.01 / 9.12 dB。没有中频全局动态失控的证据。
- V1 40 ms 窗内最大 GR >3 dB 的帧，25–70 与 70–140 Hz 的平均能量占比分别约 23.9% / 28.1%；其他帧约 11.2% / 13.6%。滤波带边缘会重叠，所以这只是方向性关联，不是严格互斥能量归因。它与父任务针对 15 个峰的伴奏/人声审计一致：许多峰由伴奏贡献更多。
- V1 整体 S/M −11.71 dB、左右相关 0.873、折单声道能量 −0.284 dB；参考整体 S/M −12.76 dB、相关 0.899。参考中频更宽，但强单声道低音又改变全局统计。既无相位缺陷的证据，也不能用参考全局宽度作为加宽目标。
- 在配平响度后的全曲范围，参考 3.5–7 kHz / 7–14 kHz 分别比 V1 高约 1.64 / 1.88 dB。这些带含镲、采样、齿音和不同编曲；不支持给现有已经多轮美化的人声/母带照抄高架增益。完整报告包含不同代表段的频带能量，不能把两个不同段落当成同一个编曲。

## 唯一建议的母带相关实验：稀疏伴奏峰修整

这是进入母带前的源头电平调整。采用立体声联动的连续乘法增益，不改变低音相位，不引入跨带分频。

- 仅考虑已验证的高 GR 时间点，同时要求同一事件附近的伴奏 50 ms RMS 至少比人声高 3 dB。
- 父任务 15 个峰审计中符合上述条件的候选为：11.184、38.297、49.177、78.769、92.991、95.184、96.487、145.630、146.282、148.960 秒。
- 每个事件先试最大 −0.35 至 −0.60 dB；总上限 −0.70 dB，不随每次鼓点普遍触发。
- 根据局部波形定位峰簇，用至少 20–30 ms 平滑进入，在峰簇附近保持 15–30 ms，约 80–120 ms 平滑释放。不能仅机械按 1 ms 最大峰中心做一个尖锐缺口。邻近事件应合并包络，增益包络至少一阶连续。
- 不给所有低频做动态 EQ，也不改非伴奏主导的高峰。不得从上面的关联直接认定每个峰都是底鼓。
- 仍使用 V1 同样的末端限制器与 −11.55 LUFS 目标，不自动增响。分别报告这些事件的 GR 与全局 P95、>3 dB 时间；只有实测负担减少且常态包络、低频能量保持时才保留。
- 本实验目标是把少量峰值的控制移回伴奏，减轻它对同时出现人声的联动压低；不保证仅凭这一步能听出显著“唱片感”。若末端增益补偿抵消收益或增加正常段 GR，则放弃。

## 不优先采用 HP120 Hz、1.2:1 总线胶合的原因

高通检测会减少低音触发压缩，但当前最值得照顾的高峰恰与低频/伴奏相关。慢攻击的低比例胶合也未必削减最尖的峰，随后响度补偿反而可能加重末端限幅；它会持续处理原本已经稳定的中频和主唱。若另有听感依据试验，总 GR 应以 P95 ≤0.5 dB、最大 ≤0.8 dB 为边界，攻击 25–40 ms、释放 120–200 ms、全立体声联动，严格同响比较；现有测量不构成必须加入的理由。

## 验证边界

- 完整 WAV 响度保持 V1 ±0.10 LU；TP 保持约 −1.4 dBTP，MP3 复核不超过 −0.5 dBTP。
- 不要求把参考 LRA、RMS、低音量或 S/M 复制过来。
- 稀疏修整前后的长段平均低频变化应非常小（例如 <0.15 dB）；若接近全局削低频，应检查候选选择和包络覆盖范围。
- 比较 11.18、38.30、49.18、95.18、146.28 秒及不应受影响的对照段。保持原时长、声像和每声道同一增益。

## 最终可实现候选（更新）

`derive_peak_candidates.py` 已扫描全曲，并把明确采样点时间及建议修整量保存到 `peak-candidates.json`。上文 10 个时间仅是父任务最初 15 个高峰审计中的子集；本次全曲规则找到 **37 个 1 ms GR 局部峰，28 个通过伴奏/低频上下文门限**。这是稀疏实验候选，不是听觉缺陷清单。

- 原末端估计 GR 至少 4.3 dB；局部峰间隔至少 150 ms，突出度至少 0.75 dB。
- 在 GR 峰的 ±10 ms 内查找伴奏真正的每样本立体声绝对峰；JSON 的 `beat_actual_sample_peak_time_s` 可直接作为修整中心。
- 以实际伴奏峰为中心的 50 ms：伴奏 RMS ≥人声 RMS +3 dB；140 Hz 低通后的平均功率与原伴奏平均功率比 ≥0.30。人声用 premaster − beat 得到，均为现有已知工程分量。
- 低通是因果滤波，仅用于足够长的上下文门限。少数短窗滤后/滤前功率比略超过 1，是相位/窗边界影响；不解释为物理上超过 100% 的能量占比。
- 建议幅度按 `clip(0.35 + 0.20*(GR−4.3), 0.35, 0.75)` dB；实际候选为 0.350–0.694 dB。最大可用安全上限 0.8 dB，无需为了“升级”用满。
- 与父任务商定的实现：5 ms 平滑进入、有限前瞻 5–8 ms、峰附近短保持、50 ms 指数恢复、左右共享同一增益。恢复尾巴要平滑收敛或在极低剩余量处截断。每次修整应看附近波形，RMS 门限不能替代亚毫秒/样本峰定位。
- V2 主唱变化后重新测最终母带，而非假定 V1 的 GR 仍精确适用。所有候选都来自 V1，不能声称自动识别出了鼓类型。
- 部分最高 GR 峰由其他成分主导而被排除；因此**全局最大 GR 不一定降低**。评价应重点看这 28 个事件的配对 GR、正常段 P95 与峰均比、总体响度以及低频长期能量；不应为了降低全局最大值扩展到人声。
