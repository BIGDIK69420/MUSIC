# V2B 平衡修改独立检查

技术检查通过；本次未进行主观试听。

- 伴奏左右声道实测增益分别为 1.49999974 / 1.49999974 dB，相对旧人声提高 1.5 dB；立体声两侧同增益。
- 新母带前混音 = 旧 V2 人声 + 新伴奏，逐样本最大误差 0；减去伴奏恢复人声的浮点舍入误差为 5.96e-08。
- 两版均为 10,285,140 帧，48 kHz、双声道，214.27375 秒，样本有限、无超满刻度。交付 WAV 为 24-bit PCM。
- 母带总响度 −11.56 → −11.58 LUFS；新 WAV −1.38 dBTP，MP3 −0.90 dBTP（渲染测量记录）。
- 30–150 Hz 全曲峰均比 17.42 → 17.14 dB；活跃 400 ms 窗口中位峰均比 10.25 → 10.27 dB，未见明显低频瞬态额外压平。
- 单声道折叠能量 -0.284 → -0.313 dB；左右相关系数 0.873 → 0.861。伴奏加大引起总体宽度变化属于预期结果。

母带重新配平后，绝对人声电平也会随总线驱动变化；+1.5 dB 指母带前伴奏相对人声的变化，不代表最终成品所有频段都提高 1.5 dB。数值检查不替代用户对伴奏存在感、节奏冲击和抽动感的等响试听。
