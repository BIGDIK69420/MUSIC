# V2B — 伴奏平衡修订

根据用户反馈“伴奏好像又不够大声”，本版将 **V2 伴奏相对人声统一提高 1.5 dB**，直接沿用 V2 的完整人声分轨，从母带前分轨重新合成。原有 EQ、空间、修音及局部伴奏处理继续沿用，没有新增这些处理。

## 下载

- `MUSIC_MIX_V2B_BALANCE.mp3` / `.wav`：完整成品。
- `MUSIC_V2_TO_V2B_COMPARE.mp3`：V2 → V2B 等响对照，共 49 秒。
- `MUSIC_MIX_V2B_BEAT.wav`：本版已提高 1.5 dB 的伴奏，供继续制作。

对照 **0–24.25 秒为原 V2，24.75–49 秒为 V2B**。每组都使用原曲 38–50 秒和 58–70 秒，中间留 0.25 秒，均配平到约 −16 LUFS。对照重点是伴奏与主唱的相对位置。

## 实际电平

- 伴奏母带前增益：**+1.5 dB**；原 V2 人声浮点分轨逐样本沿用。
- 完整 WAV：**-11.58 LUFS / -1.38 dBTP**，与 V2 的 −11.56 LUFS 基本相同。
- 完整 MP3：**-11.58 LUFS / -0.90 dBTP**。
- 新母带驱动约 **+5.03 dB**；沿用 192 kHz 过采样、−1.4 dBFS ceiling、5 ms attack / 80 ms release 的限制器。
- 近似限幅 P95 约 **1.83 dB**，活动窗超过 3 dB 的约 **1.54%**。这些是窗口估计，非限制器内部仪表，也不是对主观抽动的保证。

“+1.5 dB”指伴奏相对人声的母带前比例。整曲重新配平响度后，各部分的绝对播放电平也随总线增益改变。

## 分轨使用与记录

完整音频与分轨均保持 214.27375 秒、48 kHz / 24-bit / stereo。Ableton 导入从 0:00 对齐、关闭 Warp、推子与 Clip Gain 设 0 dB。本版 BEAT 加上[原 V2 VOCAL](../mix-v2-candidate/MUSIC_MIX_V2_CANDIDATE_VOCAL.wav)得到母带前混音，独立 PCM24 导出存在微小量化差异。完整成品另含总线处理。

V2 的 CORE／FX 也可继续使用；使用完整 VOCAL 时不要再次叠加 CORE／FX。本版仍为试听修订，正式 V1 保留不变。

`build_balance.py` 保存实际重混与导出方法，`validation.json` 保存电平和对照区间，`export-check.json` 保存文件回读结果，`balance-review.json` 保存独立平衡检查。脚本依赖原工作区的 V2 浮点分轨。没有主观试听能力；是否达到你要的伴奏存在感，以等响试听反馈为准。
