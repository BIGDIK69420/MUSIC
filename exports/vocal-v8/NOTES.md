# V8 — 《1 Call》方向的人声制作

本轮目标是参考 Tory Lanez《1 Call》的人声层次与空间取向，以用户已认可的 V7 为基础制作完整版本。参考分析见 `REFERENCE_VOCAL_ANALYSIS.md`。这是对制作感觉的尝试，不声称识别出了原曲插件配方、复刻了歌手声线或已通过主观试听确认相似。

## 先听什么

- `MUSIC_v8_1CALL.mp3` / `.wav`：完整成品，约 3:34，约 −11.04 LUFS。
- `MUSIC_v8_COMPARE.mp3`：41 秒等响对照，0:00–0:20.25 为 V7，0:20.75–0:41 为 V8。每版包含歌曲 1:00–1:12 与 1:38–1:46 两段，中间四分之一秒间隔；V7/V8 之间停半秒。两版分别匹配至约 −16 LUFS，适合比较音色与层次，而非音量。

## 人声分轨

- `MUSIC_v8_VOCAL.wav`：完整人声，含本轮新增效果。
- `MUSIC_v8_VOCAL_CORE.wav`：人声主体，含之前 V7 已印入的效果，并非原始干声。
- `MUSIC_v8_VOCAL_FX.wav`：本轮新增的微移调叠层、延迟和扩散尾声。

CORE + FX 以原音量相加等于 VOCAL（24 bit 导出仅有量化误差）。三者都是母带处理前电平；在 Ableton 从 0:00 对齐，关闭 Warp，CORE 与 FX 推子都为 0 dB 即可重组。不要同时播放 VOCAL 和 CORE+FX，否则会重复人声。若想减轻新空间，可将 FX 推子减 2–3 dB。

## 本轮处理

1. **中央主唱**：V7 原有主唱基础，10 kHz 高架 +0.8 dB，先匹配主体响度；没有再对主唱做全面压缩或深挖低中频。
2. **两侧叠层**：从已调音主唱生成，左 −7 cents / 27 ms，右 +9 cents / 43 ms，保留共振峰，滤到约 300 Hz–6 kHz。每侧活动段 RMS 初始约比中央主唱低 13.5 dB。这是制作上的微移调叠唱感，并不是真实重唱或按和弦写出的和声。
3. **跟拍延迟**：由伴奏检测得到 135 BPM / 半速 67.5 BPM；主要两侧重复在 444.444 与 666.667 ms，后续重复更轻、更暗。主滤波约 330 Hz–4.5 kHz，主唱活跃时返回降低最多 7 dB，停顿时平滑恢复。
4. **句尾延迟强调**：约 61.56、69.16、100.08、115.68、139.32、163.92、171.08、179.72 秒的活动结束前做短送入强调。这些位置来自干声活动与间隙分析，不声称已辨识歌词边界。
5. **扩散长尾**：55 ms 预延迟；低段名义 T60 约 1.35 秒、高段约 0.95 秒；低切约 450 Hz；主唱活跃时降低最多 4.5 dB。没有添加离散短房间反射。
6. **电平与母带**：完整人声较 V7 高约 0.45 LU，伴奏在母带前保留 V7 版本。整曲约 −11.04 LUFS，比 V7 提高约 1.1 LU，因此提供独立等响对照。

主唱活动段 Side/Mid 从 V7 约 −21 dB 增至约 −15 dB。参考估计人声约 −9.9 至 −9.4 dB；没有把这个不同歌曲、不同配器的数字作为硬性匹配目标。

## 参考分析为何改变制作方向

使用公开 UVR-MDX-NET-Voc_FT 模型估计分离参考 40–70 秒及 100–130 秒的人声，并用同模型检查用户独奏声的分离偏差。参考的两侧成分显著更多，而 1.2–5 kHz 比例已经比较接近。用户强声部分也已平稳，故本轮以叠层和空间为主，而非继续提高 presence 或重压主唱。参考高频可能残留齿音、气声或打击乐，只做小幅高架。

参考音频仅用于分析；参考歌手声音、参考歌曲片段或分离残留均未混入本成品，也未随本目录上传。所有听得到的人声来源均为用户原有演唱。

## 技术验证与限制

完整时长 214.27375 秒，48 kHz / 24 bit WAV 与 320 kbps MP3。WAV 约 −1.25 dBTP，MP3 约 −0.58 dBTP，未触及满刻度。限制器活动段第95百分位增益衰减约 2.55 dB；超过3 dB的活动时间约3.24%。完整混音单声道折叠能量变化约 −0.29 dB。

技术检查不等于主观试听。微移调叠层可能带来有意的合唱感；新增尾声的多少仍需用户反馈。原先录进声音的房间与旧混响没有被完全拆除。本轮参数、脚本、参考分析和质量检查已保存，可继续调整。
