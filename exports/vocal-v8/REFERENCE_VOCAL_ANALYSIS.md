# 《1 Call》参考人声估计分析

分析目的：为用户人声 V8 的制作方向提供依据。没有主观试听能力；以下为信号分析，不声称还原原曲插件链，也不声称得到真实分轨。

## 方法

- 使用公开的 `UVR-MDX-NET-Voc_FT.onnx` 模型，在 CPU 上分离参考的 40–70 秒与 100–130 秒。模型只用于分析，分离出的参考音频不应混入用户成品或上传到用户仓库。
- 模型来源：`https://github.com/TRvlvr/model_repo/releases/download/all_public_uvr_models/UVR-MDX-NET-Voc_FT.onnx`。
- 根据 UVR 元数据计算模型末 10,240,000 字节的 MD5，得到 `77d07b2667ddf05b9e3175941b4454a0`，匹配 FFT 7680、3072 频点、256 时间帧、compensation 1.021，模型采样率 44.1 kHz。
- 本地实现 scipy STFT/ISTFT，ONNX Runtime CPU 推理，模型前后 48/44.1 kHz 有理数多相重采样。
- 对比用户 V7 vocal 的相同时间区间。不同歌曲的相同时间并非相同音高、音节或配器，数值只能指导方向。
- 频谱以中心声道 300 Hz–5 kHz 能量归一；活跃帧用各片段 P95 能量以下 20 dB 的门限，另检查能量较高的一半帧，避免长静音主导结果。

## 最稳定的结论

| 指标 | 参考估计人声 40–70s / 100–130s | 用户 V7 人声 40–70s / 100–130s |
|---|---:|---:|
| Side/Mid 总能量 | −9.88 / −9.38 dB | −20.84 / −20.64 dB |
| 左右相关度 | 0.814 / 0.794 | 0.984 / 0.983 |
| 活跃 40ms 帧 P95−P50 | 3.34 / 3.15 dB | 2.36 / 1.99 dB |
| 活跃 40ms 帧 P90−P10 | 9.48 / 11.39 dB | 14.13 / 11.29 dB |

1. 参考估计人声的中频两侧明显更充分，两个片段方向一致。可以保留清楚的中央主声，增加较低电平的两侧叠层与经过避让的空间返回。不能用这些数值辨认原曲究竟用了真 double、微移调、chorus 或什么插件。
2. 参考与用户 1.2–5 kHz 的归一频谱很接近，不支持再大幅提升 presence。用户 100–130s 的 300–1200 Hz 也与参考接近，不支持继续深削低中频。
3. 用户强声已很平稳，不能因参考整曲更响就继续大幅压缩主声。若需提高连贯度，应优先微调较弱句尾和字头，而非全面压扁。
4. 参考估计人声 10–16 kHz 比用户约多 2–3 dB，但高频存在齿音、气声、分离残留不确定性。建议本轮 10 kHz 高架约 +0.8 dB，上限约 +1 dB，不做完整频谱匹配。
5. 参考 150–300 Hz 比用户少很多，但音高、元音与模型都可能影响此项。不可据此大幅去掉用户胸腔厚度。

## 分离器偏差验证

用户 V7 的 100–130s 再通过同一分离器：Side/Mid 从 −20.64 变为 −20.69 dB；300 Hz–10 kHz 的归一频谱变化约不超过 0.02 dB，10–16 kHz 变化约 +0.07 dB。说明本模型对这段独奏用户声的频谱和宽度影响很小。它不能证明参考分离没有音乐残留，但支持“约 11 dB 的宽度差不是模型对用户声的直接偏置”这一有限结论。

## 高频残留检查

参考 40–70s 中约 33% 的 10–16 kHz 能量落在仅占 6.7% 的低中频声能较弱帧；100–130s 中为约 12% / 10%。高频峰值常形成短簇，可能来自齿音、气声或残留打击乐。仅靠这些数据不能确证或排除 hi-hat 残留，也不能把全部差值都当作连续的人声空气感。

## 给 V8 的制作建议

以已被用户认可的 V7 中央主声为基底；保留中心的低中频厚度。少量微移调叠层可以作为拓展两侧的制作选择，拍同步延迟与较晚的扩散混响由主声触发避让。先把活跃段总 S/M 试探到约 −14 dB，而非机械追到参考的 −9 dB。10 kHz 只做约 +0.8 dB 的小幅高架；不增加强声的全面压缩。具体叠层和延迟不是已识别的 Tory Lanez 原始配方，而是达到近似层次的可检验实现。

原始测量见 `vocal_comparison.json`、`separation_control.json`、`high_band_check.json`、`separation_metadata.json`。参考分离音频仅留本地分析。
