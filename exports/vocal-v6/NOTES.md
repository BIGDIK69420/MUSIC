# V6：针对盒子感的两个处理版本

这次直接使用现有素材，以用户认可清晰度的 V4 为基础。OPEN 是优先试听的主版本；DRIER 提供更强的低中频与空间控制。它们是针对听感反馈的修订提案，未声称已由主观试听证实消除了盒子感，也未从频谱推断房间尺寸或身体原因。

## 文件

- `MUSIC_v6_OPEN.mp3` / `.wav`：主版本，完整 3 分 34 秒。
- `MUSIC_v6_DRIER.mp3`：更强、更干的完整备选。
- `MUSIC_v6_OPEN_VOCAL.wav`：主版本独奏人声，未经过整首歌曲的母带增益和限制器；放回本混音时使用 unity gain。
- `MUSIC_v6_COMPARE.mp3`：61 秒等响比较，取歌曲 1:22–1:42 的同一段。0:00–0:20 为 V4，0:20.5–0:40.5 为 V6 OPEN，0:41–1:01 为 V6 DRIER。每段单独匹配到约 −16 LUFS，中间有半秒停顿。完整母带约 −12.1 LUFS，因此比较文件播放更轻是有意的。

## 相对 V4 的实际改动

| 环节 | OPEN 主版本 | DRIER 更强版本 |
|---|---|---|
| 525 Hz 宽 EQ，Q 1.25 | 固定 −1 dB，动态最多再 −2 dB | 固定 −1.3 dB，动态最多再 −2.8 dB |
| 820 Hz 动态 EQ，Q 1.65 | 最多 −1.5 dB | 最多 −2.2 dB |
| 1500 Hz 宽 EQ，Q 0.85 | +0.8 dB | +0.9 dB |
| Side 的 650 Hz 宽 EQ，Q 0.65 | −3.5 dB | −5 dB |
| Side 额外增益 | 唱句内约 −0.92 dB，空隙最多 −4.15 dB | 唱句内约 −2.05 dB，空隙最多 −6.38 dB |
| Mid 空隙衰减 | 最多 −1.11 dB | 最多 −2.16 dB |

动态 EQ 根据宽频带的相对能量触发，25 ms attack / 150 ms release，左右共用控制，每个采样平滑插值。门槛取本录音活动段的统计量，只是处理设置，不表示已经检测到某个物理共振。两段最大削减不会在所有唱句同时发生。

活动控制来自用户确认未经效果处理的干声；原有调音后的声音仍是唯一听得到的人声来源。没有把原干声和已调音人声叠加，没有添加新混响、延迟、饱和或 V5 的并行 body 层。Mid/Side 不是严格的直达声/混响分离；这里压低的是这些信号成分，不能宣称完整移除了原房间。

伴奏从 V4 自己的 premaster 与对应 vocal stem 精确重组，进入母带限制器前与 V4 一致。人声先匹配 V4 的综合响度，再将完整歌曲匹配到相近的母带响度。

## 验证

`validation.json` 保存处理参数、响度、真峰值和限制器统计；`quality-check.json` 保存低频厚度、目标频带变化、弱声段电平变化、长度/格式及伴奏一致性检查。WAV 为 48 kHz / 24 bit，MP3 为 320 kbps。音频没有触及数字满刻度，单声道折叠检查通过。

代码和数值检查不能替代听感判断；请尤其比较盒子感是否减少，以及是否过薄、过干或尾字不自然。更强版不自动等于更好。

## 新参考文件的状态

用户新上传的 `1 Call.wav` 超过当前附件下载工具 32 MiB 上限，工具未将音频传入工作区。因此本版本没有分析或匹配这首参考，也不声称重现其人声链。可通过小于 32 MiB 的 MP3 或短 WAV 片段补入该参考，后续继续修订。

## 工程记录

宽谱包络分析发现约 490 Hz 的宽隆起，但分段峰值移动，因此没有使用深窄固定陷波。保守的预测式去混响试验在一个片段作用很小，强化时可能损害持续元音，本版本未采用它。可复现处理脚本为 `build_v6.py`，需要前次处理的中间文件；`verify_v6.py` 为技术验证脚本。
