# V7 — 根据《1 Call.mp3》做的参考方向试版

已成功读取用户提供的 MP3（224.05 秒）。分析的是完整混音，未分离参考人声，也没有主观试听；数据不能直接等同于主唱音色或某种插件链。

## 关键发现

- 参考整曲约 −10.02 LUFS，V6 约 −12.09 LUFS。试听时必须考虑这约 2 LU 的差异。
- 能量较强的片段里，参考在 300 Hz–5 kHz 的 Side/Mid 比约 −2.6 至 −4.4 dB；V6 约 −12.8 至 −18.1 dB。参考的中频侧向成分明显更多，但其中包含编曲、和声及效果，不能全部解释为混响。
- 以各自中央声道 300 Hz–5 kHz 的总能量归一后，参考的 150–300 Hz 相对更少约 3.4 dB；1.2–2.5 kHz 更多约 1.3 dB，5–10 kHz 更多约 5.5 dB。这些是整曲差异，不能据此给人声直接套同等 EQ。
- 因此本次保留 V6 的人声去盒子处理，尝试调整伴奏的中央拥挤与两侧展开；没有继续深挖人声低中频。

## 改动

- 伴奏：260 Hz / Q 0.85 / −1.5 dB；1800 Hz / Q 0.8 / +1 dB；6 kHz 高架 +2.5 dB。
- 伴奏两侧：增加原本存在的 250 Hz 以上 Side 信息，目标高频增量约 5 dB；无合成短延迟或反相复制。伴奏处理后重新匹配自身综合响度。
- 人声：V6 OPEN 基础上 1900 Hz / Q 0.9 / +0.6 dB；匹配响度后额外前推 0.25 dB。保留原有调音，不混入未调音干声，不添加新混响。
- 整体仍约 −12.1 LUFS，方便与 V6 公平比较；没有追随参考 MP3 的超零真峰值。

## 文件

- `MUSIC_v7_REFERENCE.mp3` / `.wav`：完整试版。
- `MUSIC_v7_VOCAL.wav`：母带处理前人声。
- `MUSIC_v7_COMPARE.mp3`：同一段歌曲 1:22–1:42，前 20 秒 V6 OPEN，停顿半秒，后 20 秒 V7；各自匹配至约 −16 LUFS。
- `analysis.json`：参考、V4、V6 的完整测量。`input_*` 才是输入文件测量值；`output_*` 是 ffmpeg loudnorm 分析过程的结果，不表示我们把原文件改成了这些电平。
- `validation.json`：V7 实际响度、峰值、单声道折叠及限制器统计。

这些改动是一版可试听的参考方向尝试，不代表已验证主观上达到参考品质。下一步以用户对 V7 的反馈继续调整；目前尚未收到 V6/V7 听感反馈。参考曲音频没有上传到仓库。
