# 混音实验 V1：历史与经验

**本次成功基线是原实验编号 V13。** 用户试听后明确反馈：“v13太棒了，作为混音实验成功的V1吧。把至今为止的经验，总结打包，并让v13成为第一版”。因此，新系列的 **混音实验 V1 = 原 V13 成品**。这是版本确立与归档，不代表需要再次改变声音。旧实验 V3–V13 的编号继续用于追溯；其中旧 V10 的失败路线不进入成功基线。

## 目标与证据怎么区分

用户最初描述的问题包括：人声和伴奏都缺少清晰度、鼻塞、盒子感、奇怪的空间、不够丰满，以及整曲浑浊或像手机录音。制作参考逐步明确为 Tory Lanez 的约 2016 年／Chixtape 4 时期，随后以《1 Call》为具体参考。

这份记录区分三种依据：

- **用户听感与取舍**：决定哪个版本更符合目标。V10 被明确否定、V11 的美化方向获认可、V13 被确认成功，都是直接反馈。
- **信号测量**：响度、频带能量、句间残留、宽度、峰值、时移与分轨重组等可复查结果。它们帮助选择处理位置、控制副作用，不能直接换算为“专业度”。
- **制作假设**：某个频带竞争是否造成遮蔽、旧空间是否造成盒子感、某种叠层是否更像参考，须由版本对照和用户试听检验。不能把假设写成唯一病因。

用户确认 dry vocal 导出时全部效果链、发送及 Master 处理均关闭。用户报告使用 UM2 + AT2020，在未经专业声学处理的小房间录音；这些是录音背景信息。屏幕约 22 cm 的距离来自用户描述，不是从文件精确反演出的测量。现有分析没有唯一确定麦距、屏幕反射路径、房间尺寸，也没有证明牙齿、颌面或共鸣腔体是这些听感问题的原因。

## 实验历史

下表从仓库可查的 V3 开始。更早版本没有在本次材料中形成足够完整的可核验历史，不补写处理细节。若对话中的听感反馈没有点名版本，就不强行分配给某一版。

| V4 | 重新平衡人声与伴奏的清晰度，并匹配 V3 响度；适度调整低中频、存在感及高架，没有追加空间。 | 用户明确说“V4是很好的改动”，同时仍觉得空间不佳、不够专业地丰满。早期还有“解决掉50%”的反馈；它是主观改善幅度，不是声学百分比测量。 |

| V9 | 检查主体、伴奏、效果及母带；减少持续衬层与低中频密度；伴奏 Mid 做条件性让位；降低限幅负担。 | 弱唱句与伴奏的中频关系比全曲平均频谱更有用。清理版仍未结束用户对浑浊的反馈。V9 伴奏处理被后续 V11／V12 保留，V13 在其上继续精修。 |

旧版 NOTES 是当时的工作记录。特别是 V10 修复报告中“从 dry 重建更可靠”属于当时的制作判断，已被后续用户否定该方向的反馈修正；不能把它继续当作当前推荐路线。

## 最有用的发现

### 1. “像手机录音”描述的是听感，不能直接等同于编码频宽不足

原始 dry 在 5–10 kHz、10–16 kHz 仍有可测能量，没有电话式 3–4 kHz 硬截止的证据。这个结果不证明高频全部有用，也不证明录音没有问题；它让后续工作不再围绕“恢复不存在的电话频宽”展开。

本次可处理输入来自 MP3 导出。交付 24-bit WAV 方便后续制作，但不会恢复源编码丢失的信息。用户的浑浊描述没有被证实主要由 MP3 编码造成。

### 2. 唱句、弱字、空隙需要分别观察

旧 wet 在 300–600 Hz 的句间／唱句能量比约 −25.7 dB，而原 dry 约 −44.1 dB，差约 18.4 dB。这说明原处理打印之后，低中频在空隙的相对占比明显提高；其中可能同时有混响、延迟、呼吸、噪声和增益处理。它不能直接作为真实房间混响时间或反射强度。

V10 曾把部分句间中低频残留相对 V9 再降低约 12–14 dB，但用户仍明确拒绝了它。因此，**残留更少是一个测量结果，不能作为新版本更好听的充分条件。**

V13 前检查发现：在规定的较弱活动帧中，约 42% 的帧在 900–1400 Hz 内伴奏 Mid 能量高于主唱主体。它给出局部让位的候选位置，不能单独证明听觉遮蔽。V13 实际处理是 900–1600 Hz 检测驱动的 1150 Hz 宽钟形让位，与“看到 42% 就把整首伴奏削掉”不同。

### 3. 丰满可以通过有时序的层次获得

V11 起保留中央主唱，在选中的持续音中渐入较低电平的两侧衬层；深空间和明显回声主要由句尾触发；主唱进入时降低返回。V12 稍加强这些原有层次，V13 再整理句头，用户最终认可。

这是这首录音的成功制作路线：**主体稳定，持续音展开，句尾保留空间，下一句进入时让主唱重新占据前景。** 它不等于每条人声都应该用相同延迟、频率、音分或混响量。

### 4. 参考曲帮助判断方向，不能提供可反推的插件配方

《1 Call》两个估计人声片段的 Side/Mid 约 −9.9／−9.4 dB，而对应 V7 片段约 −20.8／−20.6 dB；同时，两者 1.2–5 kHz 的归一频谱已经相近。这支持尝试有层次的侧向成分，也不支持盲目再加数 dB 的 presence。

这些是不同歌曲、不同音高和不同编曲下的模型估计，可能含分离残留。没有机械追到参考宽度，也没有识别出 Tory Lanez 的真实插件链。参考声音没有混入用户成品。

## 成功基线应该保留什么

1. **保留已认可的修音、主体音色和时间位置。** V11–V13 没有采用 V10 重建人声音频。旧 V10 分析中可复用的活动／周期性控制数据，也不能被描述成复用了 V10 音色。
2. **保留低中频主体。** 宽频带平均接近参考时，不继续为“干净”深挖；把偶发突出、伴奏竞争和句间返回分开处理。
3. **用局部电平处理弱字。** V13 最多 +0.65 dB 的缓慢调整，最后配平主体整体响度；没有再次全面压平主唱。
4. **空间按唱句运行。** 保留持续音衬层与句尾层次；V13 句头只对回声、深混响、浅混响分别额外最多降低 1.5／2／0.6 dB，原衬层样本保持一致。
5. **伴奏参与解决问题。** V13 的伴奏中央让位最多 −1.5 dB，保留 Side，40–150 Hz 活动能量变化约 −0.002 dB。若只继续修改人声，容易错过两者之间的竞争。
6. **比较时保持响度可比。** V12 与 V13 WAV 整曲分别约 −11.54／−11.55 LUFS；对照文件另作等响匹配。更响带来的偏好不应被误写成音色改善。
7. **保存主体、效果与当前伴奏。** V13 的内部浮点文件满足 CORE + FX = VOCAL、VOCAL + **V13 BEAT** = 母带前混音；独立导出的 PCM24 分轨相加会有极低的量化差异。旧版伴奏不能精确重组新基线。CORE 含早期打印的处理与空间，绝不是原始 dry。

## 技术核验与听感认可各自证明什么

V13 完整 WAV 实测约 −11.55 LUFS／−1.38 dBTP；MP3 约 −11.56 LUFS／−0.98 dBTP。时长 214.27375 秒；WAV 为 48 kHz、24-bit、双声道。文件回读、有限样本、峰值、分轨相加、六处唱句零时移、伴奏 Side 保持与比较片段响度均有记录。

这些检查证明导出和实现符合既定处理方案。**用户的明确试听认可，才是将 V13 确立为“成功的混音实验 V1”的依据。** 它不表示每个听感问题的物理原因都已查明，也不把技术检测通过等同于行业认证。

## 下一轮如何延续

- 将这版音频作为冻结的 V1；下一轮另建实验，获认可后确立正式 V2，保留 V1 原文件与校验值。
- 先写清具体要改善的听感和位置，再选能检验该问题的少量改动。若同时改变多项，只把结果当作整体方案比较，不宣称已证明某一个参数的因果作用。
- 同时保留等响完整混音片段与独奏对照；优先在伴奏中判断主唱的可辨度、厚度和前后位置。
- 继续检查格式、长度、真峰值、单声道折叠、分轨重组与新增处理是否符合设计。只有新改动或异常需要时才扩大检查。
- 不因某个数值更漂亮、算法更复杂或插件更多就覆盖当前成功基线。用户明确否定的 V10 音频方向不作为默认起点。
