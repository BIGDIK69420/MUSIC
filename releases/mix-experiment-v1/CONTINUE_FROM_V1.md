## 已经走通的制作方向

有效人声谱系是既有已处理／修音人声 → V4 → V6 OPEN → V7 → V11 → V12 → V13，即正式 V1。配套伴奏经过 V9 清理，再于 V13 做局部中频让位。详细来源及参数见 [处理链指南](CHAIN_AND_REPRODUCTION.md)。

保留被认可的调音、主要音色和演唱位置，采用局部电平与动态控制；持续音上选择性增加衬层，句尾留空间，句头减少新增效果遮挡。最后一个成功增量是主唱与伴奏之间的局部配合，不能把成果概括成“再提高高频”或“插件越多越好”。

## 下一次修改怎么比较

1. 从正式 V1 及其分轨开始，先写出本次具体想改变的听感与位置，再做可回退的局部尝试。
2. 保留 V1 原文件。新试验另建目录；用户认可后才确立新的正式版本 V2。
3. 将同一片段做响度配平，至少比较混音上下文；必要时再比较独奏。清晰、丰满、空间、齿音、失真与情绪由用户试听判断，测量负责排查技术异常。
4. 导出后检查峰值、编码后峰值、帧数、分轨时间与单声道表现。只有新处理或新风险出现时再增加对应检查。
5. CORE 已包含旧打印效果。导回 DAW 从零对齐、关闭 Warp，用本版 BEAT；VOCAL 与 CORE 是两种使用方式，不重复叠加。分轨只是母带前电平。

## 证据边界与交付经验

- 未对房间做独立脉冲响应或几何测量。现有歌曲不能唯一确定屏幕、墙面距离、某个反射源或用户口腔结构的贡献。22 cm 是对话中提及的信息，不是从音频确认的反射距离。
