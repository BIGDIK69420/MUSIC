# V13 — 主唱与伴奏的衔接精修

继续使用你认可的 V11／V12 人声、调音及空间层。这次的目标是改善弱字在伴奏里的可辨程度，以及唱句进入时主唱与效果的前后关系。改动属于局部精修，整体响度与 V12 基本一致。

## 下载与对照

|---|---|
| `MUSIC_v13_FINISH.mp3` / `.wav` | 完整成品，约 3:34，−11.55 LUFS |
| `MUSIC_v13_COMPARE.mp3` | V12 → V13 等响混音，再接 V12 → V13 等响独奏，共 70 秒 |
| `MUSIC_v13_VOCAL.wav` | 母带前的完整人声 |
| `MUSIC_v13_VOCAL_CORE.wav` | 人声主体，包含早先已打印的处理和部分空间 |
| `MUSIC_v13_VOCAL_FX.wav` | 本次可分开的衬层、回声、浅混响及深混响 |
| `MUSIC_v13_BEAT.wav` | 本版经过局部让位处理的伴奏 |

对照顺序：

- **0–24.25 秒：V12 混音；24.75–49 秒：V13 混音。** 每组依次取原曲 38–50 秒、60–72 秒，中间空 0.25 秒。两组编码后均为 −16.00 LUFS。
- **49.5–59.5 秒：V12 人声；60–70 秒：V13 人声。** 均取原曲 38–48 秒，编码后约 −19.99 / −20.02 LUFS。

先比较两段混音中弱字的位置，再比较独奏的句头和连贯度。正式 V12 与 V13 的整曲响度也只相差 0.01 LU。

WAV 为 48 kHz / 24-bit PCM、双声道，214.27375 秒。导入 Ableton 时从 0:00 对齐，关闭 Warp。以 0 dB 推子相加：**CORE + FX = VOCAL；VOCAL + 本版 BEAT = 母带前混音。** 不要把 VOCAL 与 CORE 再叠加。最终 FINISH 还包含总线增益和限幅。旧版伴奏不能精确还原本版混音；CORE 也不能视为原始干声。

## 本次为什么这样改

共用相同的演唱活动掩码检查 V12 主唱与伴奏中央声道时，较弱活动帧中约 42% 的帧，在 900–1400 Hz 频带内伴奏能量高于人声主体。这提供了一个局部处理方向，但频带能量本身不能证明主观遮蔽，也不能据此断言找到了所有“不专业感”的原因。

## 相对 V12 的实际处理链

1. **伴奏中央轻微让位。** 比较人声主体与伴奏中央的 900–1600 Hz 能量，以 80 ms 高斯平滑的功率作为控制依据。伴奏／主唱能量比从 −3 dB 到 +5 dB 对应控制量从 0 到 1，再由原始人声活动程度约束，使用 35 ms attack / 200 ms release 平滑。中央声道混入一个 1150 Hz、Q1.05、最多 −1.5 dB 的钟形衰减结果；Side 保留，伴奏不补偿增益。实际较强处理帧的 900–1600 Hz 能量平均减少约 0.95 dB，活动帧整体约 0.47 dB。
2. **弱字做缓慢电平调整。** 只对与上述竞争重合、周期性较明确的发声片段轻扶音量，最多 +0.65 dB，140 ms attack / 250 ms release，变化速度不超过 1.8 dB/秒。超过 +0.25 dB 的累计范围约 24.34 秒。最后整体配平 −0.13 dB，使 CORE 响度接近 V12；回读测量分别为 −18.18 与 −18.17 LUFS。这是增益自动化，没有新增修音或主唱 EQ。
3. **句头暂时减少空间遮挡。** 从原始人声电平找出 45 处唱句进入候选。于候选前 20 ms 开始调整，20 ms 进入，短暂保持后以约 100 ms 时间常数恢复。回声额外最多降低 1.5 dB，深混响 2 dB，浅混响 0.6 dB。原有句尾效果仍在。候选由信号规则决定，并非歌词识别结果。
4. **保留 V12 已有的丰满度。** 衬层样本保持一致，主唱音高和时间位置保持一致。没有叠加新的加宽或整体音色修饰。
5. **成品响度保持稳定。** 母带前增益约 +5.74 dB；4 倍过采样限幅，阈值 −1.4 dBFS、attack 5 ms / release 80 ms，关闭自动补偿并补偿延迟。最终 WAV −11.55 LUFS / −1.38 dBTP，MP3 −11.56 LUFS / −0.98 dBTP。

这是已处理人声之上的增量链。若从未经处理的录音开始，需要此前的修音、音色及空间处理，不能直接把本页参数当作完整干声 preset。之前的具体增量参数见 [V11](../vocal-v11/NOTES.md) 和 [V12](../vocal-v12/NOTES.md)。

## 核验与适用范围

- 已重新读取全部 WAV 与 MP3，核对格式、时长、有限样本及峰值，未达到数字满刻度；MP3 另做 4 倍重采样峰值估计。
- CORE + FX、VOCAL + BEAT 的重组检查通过；主唱只发生预定电平变化。六处唱句相关检查均为 0 ms 时移。
- 伴奏 Side 仅有浮点舍入误差；40–150 Hz 活动帧能量变化约 −0.002 dB；衬层样本保持一致。
- 同一演唱活动掩码下，完整人声的归一频谱各统计频带相对 V12 的整曲变化在 ±0.08 dB 内。这不代表每个瞬间都完全相同。
- 整曲单声道折叠能量变化约 −0.28 dB。约 95% 的活动毫秒窗口限幅不超过 1.84 dB，超过 3 dB 的约 1.50%；限幅数值为近似估计。

本次完成的是信号分析、处理与文件核验，没有主观试听能力；数值通过不能保证达到商业唱片的听感。参考歌只用于此前的分析，没有混入或上传参考音频。

`validation.json` 保存参数及响度，`quality-check.json` 保存回读与对照结果，`inspection.json` 保存处理前的频带观察，`controls.npz` / `competition.npz` 和 `onset_candidates.json` 保存控制曲线及候选。Python 脚本记录本工作区的实现，依赖此前版本的本地浮点音频及分析文件；并非可脱离这些输入独立运行的插件。
