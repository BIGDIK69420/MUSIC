# V9 — 针对整曲浑浊的清理试版

用户最新反馈是整首曲目浑浊、肮脏，不只人声盒子感。本轮将人声、伴奏、叠层及母带分别检查后，做整体清理；保留 V7 的调音与主体音色，以及较低电平的 V8 风格效果。

## 文件与试听顺序

- `MUSIC_v9_CLEAN.mp3` / `.wav`：完整清理版，214.27375 秒，约 −12.12 LUFS。
- `MUSIC_v9_COMPARE.mp3`：61.75 秒分步等响对照，同样的两个唱段重复三次，每组约20秒，分别匹配到约 −16 LUFS。
  - 0:00–0:20.25：V8。
  - 0:20.75–0:41：LIGHT CONTROL，减少新增效果及母带驱动等改动。
  - 0:41.5–1:01.75：V9 CLEAN，再加入人声与伴奏的清理。
- `MUSIC_v9_LIGHT_CONTROL.mp3`：完整轻处理对照，可检查较少叠层、较轻母带的版本是否已经更合适。
- `MUSIC_v9_VOCAL.wav` / `MUSIC_v9_BEAT.wav`：母带处理前的人声和伴奏，从0:00对齐、关闭Warp、推子保持0dB相加，即得到本版母带前混音。

## 发现及证据边界

- 弱唱段（原干声40ms RMS约−38至−32dBFS）里，伴奏600–1000Hz约比主唱高1.5dB、1–2kHz高0.5dB；125–600Hz则仍以主唱占优。适合分别控制主唱厚重区及伴奏对主唱的遮蔽。
- V8 新增效果中，持续微移调双轨在600Hz–2kHz比延迟、混响各高约11–14dB，是新增中频密度的主要来源。
- 但V8相对V7母带前的中央300–1200Hz只多约0.2–0.3dB，不能把全部浑浊都归因于V8。
- V8比V7更频繁受到母带限幅。没有证据据此断言V8出现严重数字波形破坏；限幅数据也不能代替主观失真判断。
- 原干声近似音高检查的中位数约186Hz、约19%的高置信度帧低于150Hz（仍有倍频歧义），因此没有照参考深削掉全部低中频。

## 本轮实际改动

1. **人声主体**：以V7为基础，不保留V8额外的+0.8dB空气感高架。增加85Hz二阶高通；250Hz/Q0.9固定−0.8dB，并在125–350Hz偏重时最多再减−0.8dB，40ms attack、180ms release。处理后匹配综合响度。
2. **伴奏退让**：仅Mid部分，在人声活动时用800Hz/Q0.8最多−2.5dB的动态处理。600Hz–2kHz伴奏相对主唱更强时作用更大，唱句间平滑恢复。Side保留，低频底座不做深削；再匹配伴奏综合响度。
3. **新增效果**：以V8母线前效果为基础，双轨−6dB、延迟−2dB、扩散尾声−3dB；新效果总线高通500Hz，减少复制到两侧的低中频。
4. **母带**：回到约−12.1LUFS。CLEAN WAV实测−12.12LUFS/−1.38dBTP，MP3 −12.13LUFS/−1.01dBTP。超过3dB限幅的活跃窗口由V8约3.24%降至约0.75%。

## 验证结果

相对轻处理对照，CLEAN活动段主唱125–350Hz约减少0.7–0.9dB；伴奏600–1200Hz相对V7约减少1.44dB。主唱更低频段因新增高通有更大的衰减，数值详见 `quality-check.json`。所有音轨时长、有限样本、声部相加及PCM格式检查通过；主成品单声道折叠能量变化约−0.27dB。

比较文件中的LIGHT CONTROL同时改变效果量、高通、V8空气感高架、人声相对电平及母带驱动；不是一次只变一个参数的因果实验。CLEAN还同时改变人声与伴奏并分别匹配响度。它们帮助判断处理方向，不证明某一项就是唯一问题。

没有主观试听能力，不声称浑浊已被确认消除。频带功率不等于主观干净度；原录音、旧插件与伴奏素材中已印入的染色仍可能存在。本轮没有继续给整曲增加高频或扩大声场。
