# V12 — 沿 V11 继续打磨

直接使用已获认可的 V11 人声主体及各效果层，保留主唱调音、主要音色、衬层音高与时间位置，继续加强持续音的连贯、两侧丰满度和句尾层次。伴奏保持 V11 所用的 V9 伴奏。

对照顺序：0–16 秒 V11 混音；16.5–32.5 秒 V12 混音；33–43 秒 V11 独奏；43.5–53.5 秒 V12 独奏。混音片段分别约 −16 LUFS，独奏分别约 −20 LUFS。正式 V11 与 V12 也只差约 0.02 LU。

WAV 为 48 kHz / 24-bit PCM、双声道，214.27375 秒。导入 Ableton 时从 0:00 对齐并关闭 Warp。CORE 与 FX 以 0 dB 推子相加得到 VOCAL；VOCAL 加上 `vocal-v9/MUSIC_v9_BEAT.wav` 得到母带前混音。不要把 VOCAL 与 CORE 再叠加。CORE 仍包含早先打印进录音的空间和动态处理，不能视为未经处理的干声。

## 相对 V11 的实际改动

1. **较弱长音轻扶稳。** 沿用 V11 的持续元音候选，只在其中较弱的部分做最多 +0.9 dB 的平滑音量调整。500 Hz–4.5 kHz 能量以约 300 ms 尺度观察，再用 100 ms attack / 180 ms release 平滑；超过 +0.25 dB 的范围约 19.24 秒。大多数活动帧接近不调整，没有重新修音。
2. **略加强已有质感。** V11 的低电平谐波残差增量提高 1.5 dB，复用原来的 4 倍过采样结果。这个数值只作用于原本约低于主唱 32 dB 的小成分，并非给整条主唱增加 1.5 dB 饱和驱动。
3. **细修高频边缘。** 6.5 kHz / Q0.9 动态最多 −1.2 dB，只在 4.8–8.5 kHz 相对语音主体突出时工作，8 ms attack / 95 ms release；中位衰减接近零。12.5 kHz 高架 +0.4 dB。主体响度配平后，相对 V11 另前推约 0.2 LU。
4. **长音两侧更丰满。** V11 衬层的 Side 增加 1.6 dB，Mid 保持原样。衬层仍是原来的 −6 / +7 音分、31 / 49 ms，持续音候选与进出位置保持一致。选中持续音内，完整人声 Side/Mid 从约 −13.55 变为 −12.51 dB。
5. **句尾空间更明显。** 原回声在停顿里最多再增加 0.8 dB，原较深尾声最多再增加 1.4 dB；主唱活动越强，这项新增增益越接近零。浅空间保持原样。延迟节奏、句尾位置、衰减时间仍沿用 V11。
6. **整体响度保持接近。** 母带目标沿用 V11，最终 −11.54 LUFS。通过效果层和局部音量塑造差别，便于公平比较这个方向是否更合意。

这是一份基于 V11 成品分层的增量处理链。若从原始干声开始制作，还需要此前的修音和处理；不能直接把这里几项参数当作完整 preset。

## 数值核验

- 完整 WAV：−11.54 LUFS / −1.38 dBTP；MP3：−11.54 LUFS / −0.99 dBTP。另用独立的 4 倍重采样峰值估算检查 MP3，约 −0.98 dBFS。
- 回读全部导出，确认 48 kHz / 24-bit WAV、正确声道与时长，样本均为有限值，没有达到数字满刻度。比较 MP3 编码后再次测量，片段响度误差不超过 0.02 LU。
- CORE + FX 与完整人声相等；人声 + 原伴奏与母带前混音相等。衬层 Mid 仅有浮点舍入误差，浅空间保持一致。
- 相同演唱活动掩码下，完整人声各统计频带相对 V11 的归一频谱变化约在 ±0.13 dB 内；主要音色保留。局部动态处理的瞬时改变可以大于这个整曲平均值。
- 完整人声活动帧动态范围 P90−P10 约 4.21 → 4.22 dB；主唱主体约 4.16 → 4.13 dB。没有新增大幅的整体动态压平。
- 六处唱句的波形相关检查未见整体时移；整曲单声道折叠能量变化约 −0.28 dB。
- 母带约 95% 的活动毫秒窗口限幅不超过 1.87 dB，超过 3 dB 的约 1.55%；这些是近似估计，不能识别所有主观失真。

没有主观试听能力，不把以上数字称为“完美”或已确认比 V11 更好听。这版的目标是延续你认可的声音，做可听、可回退的细节强化。`validation.json` 保存参数，`quality-check.json` 保存回读与比较检查，脚本保存实际实现。参考歌及其分离音频没有加入或上传。
