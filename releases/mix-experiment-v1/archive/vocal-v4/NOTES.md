**v4 — 双轨清晰度对照版**

v3 保留不变；v4 是另一版可比较的音色方案，不预设新版一定更好。目标是在人声和伴奏都缺少清晰度的反馈下，适度调整两个声部的频率平衡，同时维持 v3 已建立的响度、靠前程度和窄峰控制。

- 人声从已对齐的素材重新设置 EQ，没有在 v3 上继续叠加 EQ。保留 420 Hz 的温和削减；减少低频主体的一点重量；把存在感调整移到约 3 kHz；7 kHz 高架削减由 -3 dB 减轻到 -1.5 dB。
- 伴奏适度整理 450 Hz 附近，在约 2.2 kHz 增加存在感，并轻微提高 4.5 kHz 以上。没有使用激励器或试图凭空恢复原素材缺失的信息。
- 原版演唱期间的两处伴奏下压，改为更轻的 2.5 kHz 局部让位，避免把伴奏进一步压暗。
- 两个声部分别做响度补偿，之后合成；母带响度匹配 v3 的约 -12.07 LUFS。保留人声窄瞬态控制和过采样母带限幅。
- 这版不改变既有调音、不叠加未经对齐的干声，也不另加空间效果。

先在同一音量比较 v3 与 v4，特别关注字的辨识度、伴奏细节、厚度是否保留，以及是否更容易疲劳。更亮、薄、刺不等于更清楚；如果 v4 只是亮了，应保留 v3，而不是继续增加高频。

文件均覆盖完整歌曲。WAV 48 kHz / 24-bit；MP3 320 kbps。VOCAL_STEM 为预母带独奏文件，保留混音余量。技术验证记录见 validation.json；没有声称完成主观试听认可。
