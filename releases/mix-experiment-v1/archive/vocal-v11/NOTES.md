# V11 —《1 Call》方向的人声美化

V11 回到 V7 的原有修音与人声音色，以温和音色修饰、持续音叠层和尾句空间塑造 R&B 的丰满与层次。伴奏沿用 V9 的处理。所有新增声音均由本人的已修音人声生成；参考曲只参与分析。

| `MUSIC_v11_VOCAL_FX.wav` | 本次新增双层、延迟及混响，可单独调整其电平 |

比较文件：0–16 秒 V9 混音；16.5–32.5 秒 V11 混音；33–43 秒 V9 独奏；43.5–53.5 秒 V11 独奏。混音片段各约 −16 LUFS，人声片段各约 −20 LUFS，便于在相同播放音量下比较。V11 正式成品比 V9 约响 0.6 LU；比较文件已消除这项整体响度差异。

WAV 均为 48 kHz / 24-bit PCM，双声道，214.27375 秒，从工程 0:00 开始。导入 Ableton 后关闭 Warp。CORE 与 FX 在 0 dB 推子相加得到 VOCAL；VOCAL 与 V9 文件夹的 `MUSIC_v9_BEAT.wav` 相加得到母带前混音。不要同时叠加 VOCAL 和 CORE，否则主唱会重复。

## 这版的制作选择

**保留声音本来的加工方向。** 主唱直接采用 V7 已修音人声，没有对主唱重新移调，也没有重建成另一种干声音色。V7 已含较多音色和动态处理，所以这次只做小幅修饰：轻补 300 Hz，偶尔柔化 900 Hz 与 4 kHz 的突出部分，再加少量高频空气感。用很低电平的中频谐波残差尝试增加质感，没有增加一只持续工作的主唱压缩器。

**让宽度跟着演唱变化。** 按可信周期性和演唱活动筛选持续元音候选，双层先避开起音，再渐入、渐出。有效展开约 39.6 秒，分布于 76 个候选段；这是信号检测，不是精确的歌词或元音识别。新增双层约 −6 / +7 音分，只影响两侧衬层，中央主唱维持原调音。它们属于合成衬层，并非新录的真实 double。

**尾句才开出较深空间。** 很低的短扩散尾声用于衔接；较长尾声和明显回声只由 11 个选定句尾窗口触发。每个句尾选择一种 444 或 667 ms 的延迟节奏，重复逐渐变小、变暗，并交替声像。下一句进入时，效果进一步下压。原素材自带的混响仍存在，无法把 CORE 当成完全无空间的录音。

## 本次新增的具体设置

以下是**加在 V7 打印人声之上的增量处理**。V7 已包含此前的修音、EQ、动态及原效果链，直接给未经处理的干声套下面参数不会得到本版结果。

| 环节 | 设置 |
|---|---|
| 基础 EQ | 80 Hz 高通、12 dB/oct；300 Hz / Q0.9 / +0.4 dB；10 kHz 高架 +0.7 dB |
| 偶发突出控制 | 900 Hz / Q1.8 / 最多 −0.8 dB；4 kHz / Q1.1 / 最多 −1 dB。各自在活动信号的 P80 / P85 以上触发，20 ms attack、120 ms release；中位衰减接近零 |
| 谐波质感 | 220 Hz–2.4 kHz 的主体送入轻微非对称 tanh，4 倍过采样，去除拟合的线性部分后只保留很小的非线性残差；250 Hz–5.2 kHz 带限，仅在选中元音工作，活动 RMS 约低于主唱 32 dB |
| 持续音衬层 | 左 −6、右 +7 音分；保留 formant；31 / 49 ms 延迟；420 Hz–6.1 kHz；每声道在选中持续段约低于主唱 11.5 dB |
| 衬层包络 | 连续候选至少 350 ms；先避开起音约 60 ms，再用约 120 ms 渐入、90 ms 渐出并进一步平滑 |
| 句尾回声 | 444.44 或 666.67 ms；三次重复相对增益 1 / 0.24 / 0.07；初始带宽约 450 Hz–5.2 kHz，后续更暗；主唱活动时最多额外下压 6 dB |
| 浅空间 | 稠密扩散尾声，40 ms predelay；低／高频名义衰减约 0.65 / 0.45 s；高通约 600 Hz；较低返回量，唱歌时再压 3 dB |
| 句尾深空间 | 75 ms predelay；低／高频名义衰减约 1.55 / 1.05 s；高通约 550 Hz；仅选定句尾发送，唱歌时再压 5 dB |
| 人声位置 | 主体音色处理后先配平 V7 响度；加效果后主唱主体最终约前推 0.36 dB，完整人声约比 V7 高 0.55 LU |
| 母带 | 约 −11.5 LUFS；192 kHz 过采样限幅，设置 ceiling −1.4 dBFS、attack 5 ms、release 80 ms，补偿延迟 |

效果量按具体信号 RMS 校准，不能把这些相对 dB 数直接当作任意混响插件的发送推子或 Wet 百分比。具体门限、句尾位置及各层统计保存在 `validation.json`。如果要减弱新空间，可先单独降低 FX 的推子，保留 CORE 电平。

## 检查结果及适用边界

- 完整 WAV 为 −11.52 LUFS / −1.38 dBTP；MP3 为 −11.52 LUFS / −1.02 dBTP。母带活动毫秒窗口的 P95 限幅约 1.90 dB，约 1.63% 超过 3 dB；属于近似增益估计。
- 相同活动掩码下，CORE 对 V7 的 2.5–5 kHz 约 −0.32 dB、5–10 kHz 约 −0.01 dB、10–16 kHz 约 +0.43 dB。此次没有数 dB 的整体变暗；完整人声活动动态范围与 V7 接近。
- 新增效果活动 RMS 约比主唱低 15.6 dB；持续元音内完整人声 Side/Mid 约 −13.6 dB，其余部分较集中。整曲单声道折叠能量变化约 −0.28 dB；这不能代替对每个局部音色的试听判断。
- 参考分离出的估计人声有不同演唱、配器和分离残留。它帮助选择方向，不能识别 Tory Lanez 实际使用的插件参数，也不应把两首歌的频谱差机械当成 EQ 曲线。
- 本次完成信号分析、制作和技术检查，没有主观试听能力。是否更美、更接近你想要的《1 Call》感觉，需以成品试听为准；不会把“更宽”或“更少残留”的测量直接称为更好听。

`QUALITY.md`、`IMPLEMENTATION_REVIEW.md` 与相应 JSON 记录独立核验。`build_v11.py` 保存实际渲染方法，使用当前云工作区的源音频与控制文件；它不是独立的 Ableton 工程。参考歌、参考分离音频和模型权重未上传。
